# Pratyay Mukherjee’s academic website

**Website:** https://pratyay85.github.io/

Built with the [Academic Pages](https://academicpages.github.io/) template, with the default light appearance, author sidebar, responsive navigation, and optional dark mode.

## Edit the website

Edit the HTML below each page's YAML header. Site identity and author links are in _config.yml; the top menu is in _data/navigation.yml.

## Profile photograph

Your uploaded **PM Standard Photo.png** is used as **images/pm-standard-photo.png** without changing its image contents. Replace images/pm-standard-photo.png to update the portrait. The original uploaded file is retained in the repository.

## Theme

The actual Academic Pages template is loaded through jekyll-remote-theme at a fixed upstream revision. The theme provides the layout, fonts, sidebar, navigation, and colour themes. Local adjustments are in assets/css/custom.css. See THEME.md for provenance.

## Publishing

GitHub Pages builds on pushes to main. Repository Settings → Pages should use **Deploy from a branch → main → /(root)**. Website validation checks the build, content, local links, portrait, and desktop/mobile layouts.

## Downloadable materials

The 40 migrated WordPress media files remain under wp-content/uploads/ at their original paths. Paper links to ePrint and publishers remain external. The content/ directory is an import snapshot; the editable HTML pages are the source of truth.

See MIGRATION.md for optional custom-domain steps.
